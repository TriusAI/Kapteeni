# Model weights license & data provenance

This repository contains **no trained weights** (see `.gitignore`; artifacts
live in `model_cache/`). This document governs weights trained with this
pipeline so that anyone publishing them does it correctly.

## TL;DR

- **Code, docs, and generators in this repo:** Apache-2.0 (see `LICENSE`) —
  matching the Apache-2.0 base model.
- **Trained weights (heads, LoRA adapters, or any fine-tune of the base
  model produced by this pipeline): CC BY-SA 4.0**
  (https://creativecommons.org/licenses/by-sa/4.0/), with the attributions
  below.

The ShareAlike term comes from the training data: MultiNLI is CC BY-SA 4.0
and the underlying FEVER annotations are CC BY-SA 3.0. Whether model
weights are derivative works of training data is legally unsettled; the
cautious, community-standard choice is to release weights under the
upstream ShareAlike license with full attribution.

## Training data provenance

Licenses below were verified from the dataset cards in the local HF cache on
2026-09-24 (or from the original releases where cards defer upstream).

| Data | Source | License | Use |
|---|---|---|---|
| Qwen3-4B-Instruct-2507 | Qwen (Alibaba) | Apache-2.0 | base model (frozen backbone) |
| GoEmotions | google-research-datasets | Apache-2.0 | choice training |

| Teacher soft labels | generated from this project's prompts via a commercial cloud teacher API | see below | training targets |

**Teacher labels:** soft targets for the noul head were distilled from a
commercial cloud-hosted teacher API using prompts authored in this repo.
The labels are model-generated judgments of our own prompts against public
dataset items; treat them as covered by the license of the underlying items.

**JevBench (evaluation only):** aggregate public-half scores in
`docs/JEVBENCH.md` are quoted from the MIT-licensed
`fstandhartinger/jevbench` benchmark. No benchmark items are redistributed
in this repository. Benchmark results are self-reported; see the caveats in
that document.

## Attribution obligations when publishing weights

If you release weights trained with this pipeline, include:

1. Base model attribution: "Built on Qwen3-4B-Instruct-2507 (Apache-2.0),
   © Alibaba Cloud / Qwen team."
2. Dataset attributions for everything trained on, per the table above —
   in particular MultiNLI (CC BY-SA 4.0) and FEVER (CC BY-SA 3.0), whose
   ShareAlike terms carry the CC BY-SA 4.0 recommendation for the weights.
3. A note that Banking77 and CLINC150-trained builds inherit those
   datasets' research-use conditions where applicable.

## Note on MNLI/BoolQ/FEVER licenses

The GLUE/SuperGLUE dataset cards defer to the original releases: MultiNLI is
distributed under CC BY-SA 4.0 by NYU; BoolQ under CC BY 3.0 by Google; the
underlying FEVER annotations under CC BY-SA 3.0. If you need certainty for
a commercial deployment, re-verify against the original sources and consider
training without the ShareAlike components (the pipeline is modular — drop
MNLI/FEVER from `build_p2_passes.py`/`build_data.py` and rebuild).
